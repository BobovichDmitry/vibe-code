Данный проект - уже разработанный календарь для ведения созвонов и встреч.

Необходимо убрать из него все, что связано именно с бизнес-логикой и сделать из этого приложения готовый шаблон, в котором есть

- админ-панель с управлением пользователями (роли администратор/пользователь)
- публичная часть интерфейса, в которой выводится просто текущее количество пользователей
- публичная часть интерфейса, где выводится зашитый из админ-панели текст
- реализованный базовый e2e тест, в котором проверяется вход в админ-панель, создание пользователя и отображение количества пользователей
- подготовленные файлы по деплойменту (можно оставить текущие)
- докуметация по запуску проекта с нуля (что сделать после клонирования для запуска с docker и без на сервере с nginx-proxy и без)
- скрипты для запуска в формате удобной агентской разработки (backend, frontend, которые пишут в логи)
- agents.md для того, чтобы любой другой ии-агент мог после разрабатывать любое приложение с пользователем, но придерживаться строгих правил разработки, которые заданы сейчас в текущем проекте
- документация по примерам команд, которые можно передавать субагентам для разработки тестов, проверки через браузер, разработки докуметации

Сначлаа опиши мне рядом с этим файлом файл с планом с разбивкой на отдельных агентов, чтобы блок ответственности брал на себя отдельный агент и не раздувался контекст.

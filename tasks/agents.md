# Как работать с папкой `tasks/`

Источник истины и порядка задач — файл [index.md](index.md). Порядок — сверху вниз в разделе **Todo**.

## Режим работы

1. Берёшь верхний пункт из `## Todo` в `index.md` и реализуешь его.
2. Когда задачу выполнил — переносишь файл из `tasks/todo/` в `tasks/done/`, дописываешь в конец файла короткую секцию `## Реализация (YYYY-MM-DD)` (что сделано, ключевые файлы, как проверено, остаточные риски).
3. В `index.md` помечаешь задачу выполненной: переносишь строку из `## Todo` в `## Done` (с датой), перенумеровываешь `## Todo`.
4. Если по задаче нужны уточнения — пишешь вопросы прямо в файле задачи (секция `## Вопросы (NeedInfo, YYYY-MM-DD)`), а в `index.md` переносишь пункт в `## NeedInfo`, чтобы пользователь обратил внимание. Файл **остаётся** в `tasks/todo/`.
5. Если задачу не удалось решить технически (упало на сборке/типах и не чинится) — пункт идёт в `## Errors`, детали ошибки дописываешь в файл задачи секцией `## Ошибка (YYYY-MM-DD)`. Файл остаётся в `tasks/todo/`.

## Канонический формат `index.md`

```md
# Tasks Index

## Todo
1. [task-slug.md](todo/task-slug.md) — краткое описание

## NeedInfo
<!-- задачи, ожидающие ответа. Вопросы — внутри файла -->

## Errors
<!-- технически неудавшиеся -->

## Done
<!-- выполненные. Файл перенесён в done/, детали — внутри файла -->
```

## Скиллы и сабагенты

- `task-creator` — интерактивное создание новой задачи (диалог → финализация).
- `task-list-converter` — пакетная конвертация готового списка в файлы задач.
- `task-solver` — разобрать ОДНУ верхнюю задачу из Todo.
- `task-batch-solver` — пройти всю очередь Todo через субагентов (code-solver → e2e-writer → test-runner/test-fixer → docs-maintainer → git commit).

Сабагенты-исполнители (`.pi/agents/`): `code-solver` (реализация), `e2e-writer` (тесты), `test-runner`/`test-fixer` (прогон/починка), `docs-maintainer` (документация), `browser-checker` (браузер), `html-designer` (вёрстка).

## Slug-конвенция

`snake_case`, английский, ~2–4 слова, отражает действие/суть. Уникален в рамках `tasks/`. Нумерация префиксом `01_…`, `02_…` сохраняет порядок выполнения крупных задач.

## Ограничения проекта (из корневого `AGENTS.md`)

- **НЕ запускай dev-серверы** (`dev:backend:log`, `dev:frontend:log`) и **НЕ запускай e2e** — это делает пользователь. Проверка — только `tsc --noEmit` / `vue-tsc --noEmit` / сборка.
- **НЕ вызывай `chrome_devtools_*` напрямую** — браузер через сабагента `browser-checker`.
- Пиши на русском (формулировки, контекст, отчёты, описания в `done/`).
- Соблюдай архитектуру из `AGENTS.md` (API prefix `/api`, TypeORM, Vue 3 + Tailwind SPA, hash-router).
